Frequently Asked Questions

How do I install Best Client?

Download the Fabric Loader for your version, place the Best Client .jar file inside your .minecraft/mods folder, and launch the game using the Fabric profile.

Which versions are supported?

We actively support the latest release version. If you need builds for older versions, check out our Archive page.

What keybind opens the ClickGUI?

By default, press Right Shift in-game to open the main menu. You can rebind this at any time in the controls settings.

Where can I report bugs or suggest features?

Join our official Discord server or open an issue on our GitHub repository to reach the dev team directly.
